# Practical guides · Fiches pratiques

Short survival guides in plain text: finding water, making it safe to drink, keeping warm, calling for help. They can be read without the Survival Shelf app, on any device, with or without a network.

Des fiches de survie courtes, en texte simple : trouver de l’eau, la rendre potable, se protéger du froid, donner l’alerte. Elles se lisent sans l’appli Survival Shelf, sur n’importe quel appareil, avec ou sans réseau.

- **Français** : [ouvrir les fiches](fr/README.md)
