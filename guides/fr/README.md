# Fiches pratiques de survie

[English version](../en/README.md)

Des fiches courtes pour agir quand tout va mal. Chaque fiche répond à une seule question, commence par l’essentiel (« En bref ») et cite ses sources.

> **Important** : ces fiches ne remplacent ni les consignes des autorités ni une formation aux premiers secours. En cas d’urgence vitale, appelle le 112.

## Lire les fiches sans l’appli

Les fiches sont de simples fichiers texte, rangés par thème dans ce dossier. Tu peux :

- les lire ici, sur GitHub, en cliquant sur leur titre ;
- les lire dans l’appli Survival Shelf, page « Fiches », même hors ligne ;
- les copier sur ton téléphone, ton ordinateur ou une clé USB, puis les ouvrir avec n’importe quel éditeur de texte ;
- imprimer celles qui comptent pour toi.

Pour tout récupérer d’un coup, utilise le bouton « Télécharger toutes les fiches » de l’appli, ou le bouton vert « Code » puis « Download ZIP » sur la page GitHub du projet.

## Eau

- [Calculer ses besoins en eau](eau/calculer-ses-besoins-en-eau.md) : combien de litres prévoir par personne et par jour.
- [Stocker de l’eau](eau/stocker-de-l-eau.md) : quels récipients choisir, où les ranger, quand renouveler l’eau.
- [Trouver de l’eau chez soi](eau/trouver-de-l-eau-chez-soi.md) : chauffe-eau, tuyaux et glaçons, quand le robinet est à sec.
- [Trouver de l’eau dehors](eau/trouver-de-l-eau-dehors.md) : où chercher, quelle eau choisir, ce qu’il ne faut jamais boire.
- [Rendre l’eau potable](eau/rendre-l-eau-potable.md) : la faire bouillir, et quoi faire quand ce n’est pas possible.
- [Filtrer de l’eau](eau/filtrer-de-l-eau.md) : clarifier une eau trouble, utiliser ou fabriquer un filtre.
- [Désinfecter l’eau](eau/desinfecter-l-eau.md) : Javel, pastilles ou soleil, avec les doses.
- [Récupérer l’eau de pluie](eau/recuperer-l-eau-de-pluie.md) : la recueillir, et savoir à quoi elle peut servir.
